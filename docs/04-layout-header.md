## 実装メモ

- ヘッダーはServer Component。ログイン状態の取得は `lib/supabase/server.ts` のクライアントで行う
- ドロップダウンメニューなどインタラクティブな部分だけ `'use client'` にする
- アクティブなタブは `usePathname()` で判定する（Client Component側）
- ナビタブのリンクには `next/link` の `<Link>` を使用する
